KSTAR 助手

输入一个任务，它先在你的经验库里检索相似的坑，再生成一份带 R̂（预期达成度） 的计划。 做完之后填 R，差值 ΔR 就是下一次的判断依据。

1 · 这次要做什么

检索在本机完成，不上传任何内容；生成计划在未配置 Key 时使用模板。
AI 增强（可选，自带 Key）
配置后，「生成计划」会把任务 + 检索到的经验发给模型，生成更具体的步骤与 R̂ 建议。

2 · 计划 模板模式

就绪 · 经验 0 条 · 技能 0 个
数据来自仓库内 memory/（经验与技能元数据）。本页是静态文件，可直接双击打开或部署到任意静态托管。 无 Key 时不会发起任何网络请求；配置 Key 后仅你填写的接口地址会收到内容。
