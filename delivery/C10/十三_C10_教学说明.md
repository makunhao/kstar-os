# C10 教学说明：怎么用、怎么改、怎么教别人

## 一、5 分钟跑起来

```bash
cd agent-os
python3 scripts/kstar.py status
```

看到五层状态即成功。没有任何依赖需要安装。

## 二、一次完整循环（照着做）

```bash
# 1) 记一条原始输入
python3 scripts/kstar.py capture "今天发现：仪表盘排序按字符串长度会错" --tag 交付

# 2) 开工前写计划与 R̂
python3 scripts/kstar.py plan "修排序" --expect 0.8

# 3) 做完写经验（自动算 ΔR）
python3 scripts/kstar.py episode \
  --title "修排序：从按长度改为按编号" \
  --situation "C6A 挑战列顺序错" --task "C2A 应排在 C2 后" \
  --action "改排序键为 (数字, 后缀)" --result "网页与 Excel 同步修正" \
  --lesson "排序逻辑要在生成器里，不在产物里" \
  --expected 0.8 --actual 0.9 --tags C6A --skills dashboard-build

# 4) 复盘
python3 scripts/kstar.py reflect --since 2026-11-01 --write
```

## 三、加一个技能

```bash
python3 scripts/kstar.py skill-new my-skill --desc "一句话说明 + 触发条件"
```

然后打开 `memory/L3_skills/my-skill/SKILL.md`，补全：

- **When**：什么时候触发（写具体场景，不写"需要时"）
- **Input**：需要什么信息
- **Steps**：必须是动作（"运行 X"，不是"认真分析"）
- **Output**：产出什么、放哪

用一次之后：

```bash
python3 scripts/kstar.py skill-use my-skill --context "..." --outcome "..." --delta -0.1
```

## 四、怎么教别人（30 分钟）

| 时间 | 内容 |
|---|---|
| 0–5 | 只讲一件事：为什么记录 R̂ 比记录结果重要 |
| 5–15 | 让对方自己 `capture` 一条、`episode` 一条（用他今天真实发生的事） |
| 15–25 | 让他跑 `reflect`，看平均 ΔR |
| 25–30 | 问一个问题："你哪一次最意外？" —— 这就是 L2 的入口 |

**不要**先讲五层架构；先让他感受到"预期与实际的差"。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `status` 显示 0 条经验 | 新目录 | 用 `import_legacy.py` 导入历史，或手写第一条 |
| `recall` 搜不到 | 只做字面匹配 | 多写几个同义说法；或直接在 L2 文件里搜 |
| `episode` 报参数错误 | `--expected/--actual` 必填 | 这是刻意的：没有预期不能写经验 |
| `skill-use` 报"没有这个技能" | 拼写错误或未创建 | 先 `skill-new`；不要指望自动纠错 |
| 想删一条经验 | L2 可删，L1 不可改 | 删 L2 后同步删 `episodes.json` 里的条目 |

## 六、目录约定

- `memory/L1_raw/YYYY-MM-DD.md`：只追加。
- `memory/L2_episodes/<id>-<slug>.md` + `episodes.json`：一条经验一对。
- `memory/L3_skills/<name>/`：`SKILL.md` 必需，`usage.json`、`iterations.md` 自动生成。
- `logs/agent_runs.jsonl`：每次命令一行，可审计。

## 七、迁移到别的机器

拷贝整个 `agent-os/` 即可。没有数据库、没有绝对路径依赖、没有环境变量。
`AGENT.md` 里写的是相对路径，换机器后直接 `python3 scripts/kstar.py status`。
