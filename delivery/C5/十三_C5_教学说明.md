# C5 教学说明：怎么用这个仓库

## 一、5 分钟跑起来

```bash
cd C5交付包/repo/kstar-os
python3 -m unittest discover -s tests -v   # 应看到 9 个 ok
python3 scripts/kstar.py status
```

不需要 `pip install`，项目零第三方依赖。

## 二、用起来

```bash
# 记录
python3 scripts/kstar.py capture "今天发现的问题" --tag 交付

# 计划（写 R̂）
python3 scripts/kstar.py plan "修一个 bug" --expect 0.8

# 经验（写 R，自动算 ΔR）
python3 scripts/kstar.py episode --title "..." --situation "..." --task "..." \
  --action "..." --result "..." --lesson "..." --expected 0.8 --actual 0.6

# 检索 / 复盘
python3 scripts/kstar.py recall "关键词"
python3 scripts/kstar.py reflect --since 2026-10-01
```

## 三、看界面

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/web/
```

或直接双击 `web/index.html`。

## 四、怎么贡献

1. 先看 `CONTRIBUTING.md` 的"接受/不接受"清单。
2. 新命令必须带一个正路径 + 一个错误路径测试。
3. 提交信息写"动词 + 对象 + 原因"，不要写 `update`。

## 五、怎么部署到 GitHub Pages（维护者）

```bash
git remote add origin https://<username>:<token>@github.com/<username>/kstar-os.git
git push -u origin main
# Settings → Pages → Deploy from a branch → main / web
```

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `python3` 不存在 | Windows 只装了 `python` | 用 `python scripts/kstar.py ...` |
| 测试失败提示找不到仓库 | 在错误目录执行 | 确保 cwd 是仓库根目录 |
| `skill-use` 报"没有这个技能" | 拼写错或未创建 | 先 `skill-new`，这是刻意的严格 |
| 页面空白 | 用 `file://` 且浏览器限制 | 用 `python3 -m http.server` 打开 |
| 想清空数据 | — | 删 `memory/` 下对应文件；L1 不建议改 |
