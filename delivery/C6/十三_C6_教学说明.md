# C6 教学说明：运行、部署、改造

## 一、本地运行

```bash
cd C5交付包/repo/kstar-os
# 方式 A：直接双击 web/index.html
# 方式 B：起一个本地服务（推荐，避免 file:// 限制）
python3 -m http.server 8000
# 打开 http://localhost:8000/web/
```

无需安装依赖，无构建步骤。

## 二、配置 AI（可选）

1. 展开页面底部「AI 增强（可选，自带 Key）」。
2. 填接口地址（默认 `https://api.openai.com/v1`）、模型名、Key。
3. 点「生成计划」。成功后右上角显示"AI 模式"。

**Key 只存在当前页面内存**，刷新即清空；不会写入文件或发送到别处。
没有 Key 时，页面显示"模板模式"，这是设计，不是故障。

## 三、部署到 GitHub Pages

```bash
# 在仓库根目录
git push -u origin main
# GitHub → Settings → Pages → Source: Deploy from a branch
# Branch: main   Folder: /web
```

约 1 分钟后访问 `https://<username>.github.io/kstar-os/`。

## 四、改成你自己的数据

编辑 `web/index.html` 里的 `const DATA = { episodes: [...], skills: [...] }`：

```js
{date:"2026-11-20", title:"一次失败的经历", delta:-0.4,
 lesson:"一句话教训", tags:["标签"]}
```

改完刷新即可；不需要重新构建。

## 五、换主题 / 加功能

- 颜色在 `:root` 的 CSS 变量里；改 `--accent` 即可换主色。
- 加字段（例如"截止日期"）：先改 `DATA`，再改 `template()` 与 `aiPlan()` 的 prompt。
- 不要把 Key 写进代码；不要在页面里加"假按钮"。

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点"生成"没反应 | 没写任务 | 先填任务再点 |
| 显示"模型调用失败" | Key/接口地址/模型名错 | 看状态栏错误码；无 Key 会自动回退模板 |
| 复制失败 | `file://` 下的剪贴板限制 | 用 `http.server` 打开，或手动全选复制 |
| 手机端按钮挤 | 浏览器缩放 | 已设 `flex-wrap`；如仍挤，检查自定义 CSS |

## 七、给评审的复验清单

1. 断网打开，检索与模板计划仍可用。
2. 手机宽度 390px，无横向滚动。
3. 不填 Key 时，不应出现"AI 已生成"的字样。
4. 填错 Key，应回退模板并显示错误，而不是白屏。
