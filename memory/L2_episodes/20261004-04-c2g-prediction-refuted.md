# C2G：3-seed 对照推翻了「4096 词表更好」的预测

- 日期：2026-10-04（导入）
- 来源：`.workbuddy/memory/2026-10-04.md`
- ΔR 说明：按当时记录事后标注

## S — Situation
按公式预测 vocab 4096 的 BPB 会低于 1024，并据此安排消融实验。

## T — Task
用 3 个 seed 验证预测是否成立。

## A — Action
SP1024 / SP4096 各跑 3 seed，计算 BPB 均值、标准差与配对差。

## R — Result
BPB 均值 1024=0.77705，4096=0.78732，差 +0.01027；配对方向不一致；val_loss 比 1.3467 > 阈值 1.3291，判定为欠训练，不推翻官方榜单。最大产出是发现 4096 的 seed 方差是 1024 的 13.6 倍，改变了 25 美元算力分配。

## ΔR — 预期 vs 实际（事后标注）
- R̂：0.8
- R：0.3
- ΔR：**-0.500**

## 教训
预测被推翻不是失败，隐藏前提（训练是否收敛）才是。判据和结论必须用同一套 tokens/byte 口径。
