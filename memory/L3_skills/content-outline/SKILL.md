# content-outline

## What
输入一段真实经历（做过什么、数字、踩坑），输出：目标读者、一句话结论、六段结构、10 个候选标题、每段需要的证据。

## When to Use
- C7 文章、C5A 仓库分析转公众号、C9 周报。
- 任何「有素材但不知道怎么组织」的写作。

## Input
- 经历：时间、动作、工具、结果数字
- 读者：谁、他们现在卡在哪
- 可用证据：截图、日志、文件路径

## Steps
1. 先写一句话结论（读者只记这一句，必须能独立成立）。
2. 按「痛点 → 背景 → 过程 → 结果 → 反思 → 行动」排六段；每段先写证据，再写文字。
3. 删掉没有证据的形容词；每个数字标出处。
4. 标题用公式：数字+结果 / 反常识 / 过程+结果 / 痛点+方案；至少 10 个再选。
5. 手机阅读检查：每段 ≤3 行，每 300 字一个图或代码块。

## Tools
无脚本；纯结构化写作。

## Output
outline.md（六段 + 标题候选 + 证据清单）。
